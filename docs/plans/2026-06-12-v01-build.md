# synthdata-no v0.1 Implementation Plan

> **For agentic workers:** subagent-driven; **sonnet** implementers, **opus** review panel.
> Research base (read FIRST, it answers most "how" questions):
> `alt-wiki/tech/norwegian-synthetic-health-data-2026.md` + `docs/CONCEPT.md` + `DECISIONS.md`.
> Owner decisions locked 2026-06-12: package name **synthdata-no** (import `synthdata_no`),
> diagnosis codes = **ICD-10 code-only** (no Norwegian display text embedded), scope **full P0–P4**.

**Goal:** pip-installable generator of synthetic Norwegian health data — persons with Tenor-range
fnr/D-nr, gold-spanned bokmål clinical snippets, no-basis-aware FHIR R4 bundles, tabular sets —
with ready fixtures for medspacy-no, fhir-safety-harness, and omsorgsradar's anonymize demo.

**Architecture:** one foundation task (serial — everything depends on it), then three parallel
family tasks with disjoint file ownership, then one serial release task, then a 3-reviewer panel.

**Tech stack:** uv · Faker (`no_NO` — names/addresses ONLY, never `ssn()`) · numpy (seeded
`default_rng`) · `fhir.resources` 8.x **R4B sub-package** · `fhir-validator` (offline JSON-schema)
· pandas/pyarrow for the SSB snapshot · MIT license.

## Non-negotiables (from DECISIONS.md + research — every implementer reads these)

1. Every fnr/D-nr: month+80 (81–92); D-nr additionally day+40; mod-11 AFTER offsets; k1/k2=10 →
   discard-and-regenerate (~17% of stems); individnummer century ranges (000–499→1900s,
   500–749→1855–1899∕2000–2039, 750–899→2000–2039, 900–999→1940–1999); sex parity (3rd individ
   digit even=F/odd=M). Checksum vendored from omsorgsradar `core/anonymize/pii.py` with attribution.
2. **`Faker.ssn()` is forbidden** — it emits valid REAL-range fnr. A guard test asserts no
   generated identifier ever has month ≤ 12. Use locale `no_NO` (there is NO `nb_NO` — it silently
   falls back to en_US; test this assumption).
3. One seed → byte-identical output, every family. No unseeded randomness on any default path.
4. Embedded code lists: ATC+varenavn from **FEST** (NLOD 2.0, attribute DMP — copy norfest's
   THIRD_PARTY_SOURCES.md pattern), **LOINC** handful (Regenstrief attribution notice verbatim),
   **ICD-10 codes WITHOUT Norwegian display names** (display field omitted; user-supplied display
   file supported). NO ICPC-2, NO SNOMED, NO WHOCC-direct ATC, NO NLK/NPU.
5. Kommune codes from SSB KLASS (cls 131) — fetched by a documented script into a committed
   snapshot; never hand-written.
6. Honesty framing everywhere: «no real persons, no re-identification risk by construction, NOT
   for statistical inference»; never "representative of Norwegian EPJ/population"; physician
   sign-off checklist (`PHYSICIAN_REVIEW.md`) gates any realism claim.

## Task X — Clinical text family (parallel, 1 sonnet; owns `text.py`, `templates/`, `export/medspacy.py`)

- [ ] X1 Template engine TDD: templates as data (TOML/JSON under `src/synthdata_no/templates/`),
  each template = pattern with slots (`{entity}`, `{trigger}`, `{section}`) + the gold outcome it
  encodes. Rendering computes **char-offset spans** for the entity and emits one JSONL record:
  `{"text", "spans":[{start,end,label,token_start,token_end}], "meta":{gold_context, trigger,
  section, template_id}}` (exact shape in wiki §medspacy-no contract). `gold_context` ∈
  {NEGATED_EXISTENCE, POSSIBLE_EXISTENCE, HYPOTHETICAL, HISTORICAL, FAMILY, AFFIRMED}.
- [ ] X2 Template inventory (data authoring — cite each cue's source list in a comment):
  pre-negation (ikke/ingen (tegn til)/uten/fri for/aldri hatt + word-order variants),
  post-negation (mangler/benektes/negativt/u.a./i.a.b./utelukket), uncertainty (mistanke om/
  mulig/suspekt/sannsynlig/obs mulig), **pseudo-negation traps** («kan ikke utelukkes», «ikke
  utelukket», «ingen endring i», «ikke bare» → POSSIBLE/AFFIRMED, never NEGATED),
  **conjunction-scope traps** («ikke X, men Y» → X negated + Y affirmed in ONE record with two
  spans; «verken/hverken X eller Y» → both negated), HYPOTHETICAL (hvis/dersom/ved behov),
  HISTORICAL (tidligere/gjennomgikk/anamnestisk), FAMILY (mor/far/søsken har, hereditet for),
  abbreviation-bearing sentences (ca., pas., bt., temp., evt., pga., tbl., i.v.), and section
  frames for the 15 heading families × {Plain:, UPPER, no-colon} variants. Entity slot fillers:
  a small neutral condition/symptom list (no licensing issue — plain Norwegian words).
- [ ] X3 `export/medspacy.py`: `to_jsonl(path, n, seed)` + `to_spacy_examples(jsonl_path, nlp)`
  adapter producing `spacy.training.Example`s (spaCy optional dependency, lazy import).
  Tests: every emitted span's text slice == the intended entity string (offset integrity, incl.
  multi-byte æøå!); per-category counts ≥ medspacy-no release thresholds; pseudo-negation records
  assert gold_context != NEGATED_EXISTENCE; determinism; JSONL round-trips. Commit `P2: …`.
